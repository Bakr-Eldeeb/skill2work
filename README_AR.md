# تشغيل Skill2Work النهائي على ويندوز

ثبّت Node متوافقًا: سلسلة 24 بداية من 24.15، أو سلسلة 22 بداية من 22.22.3، أو سلسلة 26. تم الاختبار على Node 24.22.1 وnpm 11.9.0.

فك الضغط وافتح Terminal داخل مجلد `skill2work-angular` بجوار `package.json`:

```powershell
npm ci
npm start
```

افتح http://localhost:4200/ واترك نافذة الأوامر مفتوحة. للإيقاف اضغط Ctrl+C.

لو ظهر أن 4200 مستخدم، أوقف السيرفر السابق من نافذته بـCtrl+C ثم شغّل `npm start` مرة أخرى. لم نغيّر المنفذ الافتراضي. ويمكن بدلًا من إيقاف أي برنامج آخر تشغيل:

```powershell
npx ng serve --port 4201
```

ثم افتح http://localhost:4201/. بيانات الديمو منفصلة لكل عنوان/منفذ.

كلمة المرور الافتراضية للحسابات: `Demo123!`

| الدور       | البريد                     |
| ----------- | -------------------------- |
| باحث عن عمل | candidate@skill2work.demo  |
| شركة        | company@skill2work.demo    |
| جامعة       | university@skill2work.demo |
| مدير النظام | admin@skill2work.demo      |

صفحة الإعدادات لا تعرض كلمة المرور الحالية ولا تملأها تلقائيًا. اترك حقل كلمة المرور الجديدة فارغًا للحفاظ عليها. حساب الجامعة عند تعديله يتبع القاعدة نفسها.

المهارات وجواز المهارات والنتائج أصبحت تبويبات داخل مساحة واحدة. البحث عن المواهب والتوصيات في مساحة واحدة للشركات، والمتقدمون ومراحل التوظيف في مساحة واحدة. تفاصيل المعرض تحتوي أقسام النظرة العامة والشركات والتسجيلات والوظائف. الروابط القديمة تعمل، وزر الرجوع يرجع للصفحة المناسبة داخل نفس الدور.

يمكن التقديم بدون تقييم. التقييم محاكاة ثابتة وليس ذكاءً اصطناعيًا حقيقيًا. التقييم الكامل الأول يشمل المهارات غير المقيمة؛ إعادة التقييم تشمل المهارات التي انتهت فترة انتظارها ٢٤ ساعة. انتهاء الوقت لا يختلق إجابة ويحفظ النص الجزئي الفعلي. الإجابات والمسودة يمكن استعادتها بعد انقطاع قابل للاسترجاع.

استخدم بيانات وهمية فقط؛ تسجيل الدخول والتخزين محليان وغير آمنين للإنتاج. حساب الشركة الجديد يحتاج موافقة مدير النظام، وحسابات الجامعات ينشئها مدير النظام فقط. البيانات محفوظة في نفس المتصفح. تغيير الجامعة يلغي تسجيلات معارض الجامعة السابقة دون حذف طلبات التوظيف التاريخية.

للاختبارات:

```powershell
npm run build
npm run test:domain
npm run test:dom
npm run test:ux
```
