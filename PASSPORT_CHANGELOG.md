# Interactive Skill Passport changes

Based on the V4 Real Platform source with the Find Jobs footer fix. This archive is an independent review copy.

- Added a violet textured cover, original Skill2Work medallion, paper leaves, identity watermark and dated teal assessed-skill stamps.
- Added a responsive reader with a section index, page counter, keyboard controls, RTL turns and a reduced-motion alternative. Small screens keep the new page heading in view.
- Connected the reader and list to the same profile, results, per-skill scores and existing overall calculation. Results deep links support one-click switching back to either display.
- Moved the existing 24-hour timing rule into a shared function used by the reader and assessment workflow. Available actions update when the cooldown ends.
- Added localized passport text, an initials fallback for holder photos and regression coverage for zero scores, missing evidence, state retention, accessibility and repository-relative deep links.
- Included actual browser captures and a short animated review. No package dependency, backend contract or deployment configuration changed.
